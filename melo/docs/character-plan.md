# Melo 动态角色设计与实现计划

目标：在现有首页实现用户需求中的动态音乐伙伴，保持现有聊天和音乐功能可用。用户要求一次完成，设计与实施自主进行。

采用 React、TypeScript、Framer Motion 与 SVG 分层的 2.5D 方案。完整人物通过共享身体、头发、耳机、衣服、手臂资产组成；眼睛、眉毛、嘴巴使用参数化路径，450ms 过渡。头像选择器复用同一面部组件。无新增大型运行时，无外部图片依赖。

1. 编写浏览器验收：默认开心、七种表情、选择器、点击、音乐、聊天入口、减少动态、移动端溢出。
2. 建立统一 Expression 类型及 useExpression 接口，与已有 useLiveMelo 状态连接。
3. 制作 SVG 分层人物、表情组件、随机眨眼、指针跟随、悬浮音波与伴随机器人。
4. 改造 Hero，新增头像选择器、音乐试听入口和首屏布局。
5. 接入聊天发送/成功回复、收藏成功、音乐播放的表情反馈。
6. 运行类型检查、生产构建、桌面和移动端浏览器验收，检查截图，修复问题，保存交付说明。

边界：不改服务端身份/数据隔离，不对外发布；此任务交付可本地运行的首页角色。音乐仍为项目原有程序合成音乐。
