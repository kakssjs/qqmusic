# Melo 豆包语音本地审核

用户点击“语音聊聊”才请求麦克风、票据和实时连接。未点击默认 idle；结束或失败释放麦克风，不自动恢复音乐。进入后一次温柔问候，根据真实表达适度关切，不诊断、不过度追问。

后端持有凭证，已忽略的 .env 不提交。连接使用匿名会话签发的 30 秒一次性票据，校验来源，限制并发和连接时长；WebSocket 直连后端，Vercel 仅代理票据。

验证：TypeScript、构建、新增 TSX lint、二进制协议/票据检查及后端测试通过。真实豆包返回文字和 PCM 音频；本地后端桥接真实服务返回 ready、音频及保存确认。网页 DOM 默认 idle。用户麦克风实际识别与扬声器回声需要人工试用，未代替用户开启麦克风。

修复了取消后继续请求麦克风、就绪超时、最终识别消息丢失、结束刷新先于保存、结束后迟到事件和卸载后的等待资源问题。

这是本地审核版本，尚未推送或部署。后端本地 8086，网页预览 4173；本地静态输出配置指向本地服务，未修改正式站点后端地址。正式发布前需要同步 ECS 依赖/模块及服务器环境变量，并恢复构建输出的正式配置。
