# qqmusic

Melo — AI 音乐陪伴伙伴。让音乐听懂你的情绪。

## 文件夹内容

- `melo/`：网站源码、组件、样式、项目文档、验证脚本与运行所需的公开素材。
- `assets/`：项目视觉素材。
- 根目录 PNG：参考图、桌面与手机页面效果图、人物表情和过渡效果截图。

## 本地运行

进入 `melo` 文件夹，安装依赖后运行开发服务：

```sh
npm install
npm run dev
```

聊天与数据存储功能需要配置自己的服务凭据和运行环境，详情见 `melo/README.md`。本仓库不包含私钥、API 密钥、本地数据库、依赖包、缓存或部署压缩包。
